# Interaction patterns

- Sticky narrative: scroll progress chooses the pain-point item while the stage remains pinned.
- Sticky stack: service panels pin independently and replace the visible layer in document order.
- Direction-aware navigation: last scroll position determines whether the fixed header is shown.
- Copy swap hover: nav labels contain two vertically offset copies that translate together.
- Local media control: only the front hero video responds to its play/pause control.
- Single-open disclosure: FAQ stores one active index and exposes matching ARIA relationships.
- Segmented control: pricing stores billing cadence and animates the active pill.
- Ambient motion: logo/ribbon marquees and autoplay loops are presentational and stop for reduced motion.
